# P1: Alerts you can set and silence (Ultra)

Branch `wip/p1-alerts`. Logic in `src/alerts.rs` (pure, tested). Menu and Win32 wiring in `src/ui.rs`.
Config fields in `src/config.rs`. Builder decisions are in [p1-handoff.md](p1-handoff.md); this file adds the
finisher's decisions at the end.

## What was built

Everything is in the tray menu under **Alerts**. Ultra build only.

- **Presets per symbol.** Each symbol in the Alerts submenu lists the presets below. A preset is greyed when
  it cannot be set right now (no fresh CNBC price, or the day field is missing).
  - Percent of the current price: above 0.5, 1, 2 and 5 %; below 0.5, 1, 2 and 5 %.
  - Past today's high (above) and past today's low (below): one tick beyond the extreme, where a tick is one
    unit of the last displayed digit. Exactly at the extreme does not trip them. Also the previous close.
  - Day move: plus or minus 1, 2, 3 or 5 %, on either sign.
- **What is set.** A greyed line under the presets says what the alert holds, for example
  `above 4,200.00 · below 3,900.00 · day ±2 % · once`, or `nothing set`. **Clear this symbol's alerts** removes
  every level for that symbol.
- **Fire once, then clear.** A checkbox. When it is on, a new alert fires one level and then drops that level;
  an alert with no level left is removed. Toggling it also changes every existing alert.
- **Mute.** *For 1 hour*, *For 8 hours*, *Until I turn it back on*, and *Unmute*. The submenu title reads
  `Muted until 14:30` while a timed mute runs. A timed mute ends by the clock; nothing has to reset it.
- **Quiet hours.** Off, 22:00 to 07:00, 23:00 to 08:00, or 00:00 to 09:00, in this PC's local time.
  During quiet hours an alert is still checked and logged, but it shows no balloon and makes no POST.
- **Webhook.** The menu shows `Sends to <host>` only. *Paste URL from clipboard* reads the clipboard on the
  click, validates it, and asks "Send alerts to <host>?" before saving. *Send a test alert* posts a fixed test
  message. *Remove* deletes the URL. The webhook is a bearer secret: it is never shown, logged or put in an
  error message. Only its host is displayed.
- **Recent.** The last 10 alerts, newest first, one line each: time, title and outcome (`shown`, `muted`,
  `quiet hours`, `sent`, `send failed`). *Clear list* empties it. The list is in memory only, so it is gone
  after a restart.
- **Tray marker.** When an alert fires, the tray icon gets a white disc with a dark rim (bottom right) and the
  tooltip's first line reads `Alert: <title>`. Both clear when the panel is expanded or any menu is opened.

Firing rule (unchanged from the skeleton): an alert fires only on a fresh quote, when the price is on the
alert's side of its level (`>=` for above, `<=` for below), or when the absolute day change reaches the day move.
Each alert waits `cooldown_s` (minimum 30 s) between firings. A silenced alert still fires internally: it
burns its cooldown and is logged as muted or quiet, so lifting a mute does not release a burst.

## Config fields

All new fields default to today's behaviour, and `{}` still parses.

| Where | Field | Default | Meaning |
|---|---|---|---|
| `Config` | `alert_once` | `false` | New alerts copy this as their `once`. |
| `Config` | `alerts_muted` | `false` | Indefinite mute. |
| `Config` | `alerts_mute_until` | `0.0` | UTC seconds. A timed mute ends when the clock passes it. |
| `Config` | `quiet_hours` | `None` | `[from, to]` in minutes of the local day, `[from, to)`. Wraps midnight when `from > to`. `from == to` is off. |
| `Alert` | `day_move` | `None` | Absolute percent day change that fires the alert. |
| `Alert` | `once` | `false` | Clear the level that fired. |

No secret is displayed. `webhook` already existed; the menu shows only its host.

## Decisions

Builder decisions (from the hand-off, kept as they were):

- `WM_APP + 6`, `+ 7` and timer 4 are unused. A timed mute ends by the clock. The webhook result reuses `WM_ALERT`
  (`wparam` 1 is failure, `lparam` is the log sequence number).
- "Past today's high" is `Above(high + tick)` and "past today's low" is `Below(low - tick)`, with
  `tick = 10^-digits`. The price must go past the extreme, so it does not fire at once when already there. If
  `low - tick` is not positive, the preset has no level. (Reviewer decision, replacing the first rule, which fired
  at the extreme itself.)
  The previous close is `Above` when the price is under it, `Below` when over, and absent when equal.
- A day-move preset needs only a fresh CNBC reference price.
- One `Fired` per alert per pass. A price level wins over a day move when both are reached.
- A silenced `once` alert still loses its level. It shows up in Recent as muted or quiet.
- *Fire once* is a global toggle that rewrites `once` on every alert.
- The test alert is logged as "Test alert". It ignores mute and quiet hours, does not set the tray marker, and is
  refused for 15 s after the previous one.
- The tray marker is drawn in `make_icon`; `icon_link` is `Option<(Link, bool)>`.
- "Muted until HH:MM" uses the offset implied by the current local minute, so a DST change inside a mute window
  is an hour off.
- Saves from new code go through `save_cfg()` outside `with_ui`.

Finisher decisions:

- `describe` lists only levels that can fire. A NaN or infinite level, and a day move that is not a positive
  finite number, count as not set. An alert with only `once` set (no level) reads `nothing set`.
- `accept_webhook` returns one of four fixed sentences: empty, longer than 2,048 bytes, spaces or control
  characters, or not a web address. None quotes the input. Scheme and host are checked with `redact`, which also
  rejects `https:SECRET`-style shorthand.
- `quiet` is a plain half-open window test. `to` is always outside, and `from == to` is never inside.
- `entry_line` shows a time from `local_hhmm`. A NaN entry time shows the current local time.
- Edge tests added: NaN price (never fires), a price exactly on a level (fires), NaN or zero day move (never fires),
  cooldown 0 or NaN (floored to 30 s), presets with a negative or NaN reference, the log at exactly 10 and 11
  entries, and `set_outcome` on an unknown sequence number.
- `source.rs` already refuses non-positive or non-finite CNBC prices (`price <= 0.0` returns `None`), so a zero
  price never reaches `check`.

## Contracts I think are worth a second look

- Resolved by the reviewer: "past today's high/low" now needs one tick beyond the extreme, so a price already
  at the extreme does not fire.
- A silenced `once` alert consumes its only level without anyone hearing it. A reviewer may prefer that a
  silenced `once` alert keeps its level until it is actually shown.
- The webhook POST error strings in `source::post` are fixed (`HTTP <code>` or `network`). The alert thread adds
  only the redacted host, so no URL reaches the log.
