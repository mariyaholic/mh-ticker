The published Windows executable is v1.2.3. Download it from that release and start it to use the taskbar strip. The source is 1.8.0, which is not released yet, and it builds Classic and Ultra. The published download is older than the source, so do not assume any feature from 1.7 or 1.8 is in the v1.2.3 download.

How it works

The panel displays price age; a stale or offline indicator means the quote is not current. Quote requests use the network. Optional webhook destinations should be treated as secrets.

The 1.8.0 source adds the following. Alerts and the chart are Ultra only. Symbols and the everyday settings are in both builds. The keyboard and card menu are Ultra, except Ctrl+C, which works in both.

  • Alerts: presets by percent, past the day's high or low, the previous close and the day move; an exact level; fire once; mute and quiet hours; a webhook pasted from the clipboard; a recent list.
  • A candle chart: a hover readout, local or UTC time, reference lines, ranges from 1D to 5Y, volume, and alert levels.
  • Symbols: type one to add it, after a check against CNBC; up to 24 on the strip.
  • Keyboard and cards: arrow keys to move a lock, a card menu to move and remove a card, and a click on a docked strip symbol to open its card.
  • Everyday: start with Windows, a global hotkey, refresh now, strip rows, text size and opacity, check for updates, and copy all prices.

Requirements and commands

Windows 10+; Stable Rust for source builds.

Run these from the source checkout where applicable. Commands were source-inspected for this documentation; environment-specific execution is not claimed.

cargo test
cargo build --release

Limits and safety

Price information is illustrative and is not investment advice. Verify the executable’s release and checksum before running it.

The 1.8.0 features were tested under Wine and in the native Windows CI run. Nothing was clicked on a Windows desktop, and the CNBC chart-range files have not been checked live. The --probe command is the check for those.

Requests: CNBC serves the prices, the charts, the range files and the symbol check. The update check goes to api.github.com, and only when it is clicked. The optional fallback providers are off by default. Each symbol on the strip adds to the requests made on every refresh, and the cost at 24 symbols has not been measured.
