`mh-ticker/index.html` is the 1.8.0 documentation page for MH Ticker, a drop-in replacement for `docs/mh-ticker/index.html` in the site repository (`mariyaholic/mariyaholic.github.io`).
It keeps the original structure, classes, ids, header, navigation, table of contents and footer, and stays one line of static HTML.
The site's rule is a branch and a pull request, which the owner merges.
Nothing was pushed to the site repository: it was read, never written.
The page says plainly that the published download (v1.2.3) is older than the 1.8.0 source, and its links to `main` resolve once 1.8 is on `main`.
